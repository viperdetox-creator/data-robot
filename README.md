# data-robot

A small GitHub Actions robot that records the daily Wikipedia page views of three pages.

It runs every day at 02:17 UTC (07:47 India time) and appends the views to `pageviews.csv`.

Pages:

- `Virat_Kohli`
- `Interstellar`
- `Pathanamthitta`

Page-view data: Wikimedia Foundation (CC0 1.0).
